# AWS Cloud Practical

**Name:** Ayan Sayyad
**Technology:** Amazon Web Services (AWS)
**Platform:** Ubuntu 24.04 EC2

## About

This repository contains my AWS cloud practicals and hands-on experiments performed using AWS EC2, S3, AWS CLI, CloudWatch, EBS, and Apache Web Server.

## Practicals Covered

1. AWS CLI Installation on Ubuntu
2. EC2 Instance Setup
3. Apache Web Server Installation
4. EC2 Bootstrap / User Data
5. S3 Access from EC2
6. CloudWatch Agent Setup
7. CloudWatch Log Monitoring
8. CloudWatch RAM Monitoring
9. CPU and System Stress Testing
10. EBS Volume Creation and Mounting
11. Uploading Data to Amazon S3

## Technologies Used

* AWS EC2
* Amazon S3
* AWS CLI v2
* Amazon CloudWatch
* Amazon EBS
* Apache2
* Ubuntu 24.04
* Linux
* Bash

## Important Security Note

AWS Access Keys, Secret Keys, passwords, private keys, and other sensitive credentials are **not included** in this repository.

For EC2 access to AWS services, IAM Roles are preferred instead of storing access keys on the server.
